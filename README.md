# Gurupreeti Mehra — Material 3 Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript. The visual language is inspired by Material Design 3 expressive patterns: rounded surfaces, tonal color, accessible focus states, and a light/dark theme.

## Run locally
1. Unzip the folder.
2. Open `index.html` in your browser.

No build step or package installation is required. Google Fonts and Material Symbols load from Google Fonts when you're online; the layout and content still work without them.

## Personalize before publishing
Search the files for these example values and replace them:
- `gurupreeti@example.com` — your real email
- `https://github.com/` — your GitHub profile/repository links
- `https://linkedin.com/` — your LinkedIn profile
- `Your school name`, `Year – Year`, and the education dates
- Skills, project links, and achievements you want to claim publicly

The AI Study Buddy item is labelled as a concept. Keep it labelled as a concept unless you actually build it. Remove any skill or achievement you cannot confidently explain.

## Features
- Responsive mobile and desktop layout
- Mobile navigation menu
- Light/dark theme toggle (preference saved in local storage when available)
- Smooth in-page navigation and active section indicator
- Back-to-top button
- Semantic landmarks and keyboard focus styles
